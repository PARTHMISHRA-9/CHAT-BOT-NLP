# AI Chatbot using NLP

This project is a simple AI chatbot built using Python and Natural Language Processing (NLP) techniques.

## Technologies Used
- Python
- NLTK
- Scikit-learn

## Features
- Responds to user queries
- Uses NLP techniques like tokenization and lemmatization
- TF-IDF based similarity matching
- Easy to modify knowledge base

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the chatbot:
   python chatbot.py

3. Type messages in terminal and interact with the chatbot.
